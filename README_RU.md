# 🛠️ Набор инструментов для Lenovo Xiaoxin Pad Pro GT (TB710FU)

Набор утилит и подробных руководств для управления, модификации и прошивки планшета **Lenovo Xiaoxin Pad Pro GT (TB710FU)**.

&gt; ⚠️ **ВАЖНО:** Все действия выполняются на ваш страх и риск. Модификация системных разделов может привести к потере гарантии или превращению устройства в «кирпич». **Всегда делайте резервные копии перед началом.**

---

## 📚 Проекты

Этот набор инструментов состоит из взаимосвязанных проектов. Выберите тот, который соответствует вашей задаче:

### 🧹 1. [Удаление мусорных приложений TB710FU](TB710FU-bloatware-uninstaller.md)
Лёгкий, портативный скрипт для отключения OTA-обновлений и удаления предустановленного мусорного программного обеспечения.
* **Назначение:** Автоматически отключает неработающие OTA-обновления и упрощает удаление предустановленного bloatware на планшете Lenovo Xiaoxin Pad Pro GT (TB710FU) через ADB. Дополнительно производит оптимизацию сервисов Google на китайской прошивке.
* **Особенности:** Использует безопасное удаление через `pm uninstall --user 0` с возможностью полного восстановления приложений. Легко настраивается путём редактирования списка пакетов в `.bat` файле.
