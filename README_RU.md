# 🛠️ Инструменты и инструкции для Lenovo Xiaoxin Pad Pro GT (TB710FU)

Коллекция утилит и подробных руководств для управления, модификации и прошивки **Lenovo Xiaoxin Pad Pro GT (TB710FU)**.

> ⚠️ **ВАЖНО:** Все действия вы выполняете на свой страх и риск. Модификация системных разделов может привести к потере гарантии или превращению устройства в «кирпич». **Всегда делайте резервные копии перед началом работы.**

---

## 📚 Проекты

Этот набор инструментов состоит из взаимосвязанных проектов. Выберите тот, который соответствует вашей задаче:

### 🧹 1. [Удаление мусорных приложений TB710FU](TB710FU-bloatware-uninstaller_ru.md)
Легковесный портативный скрипт для отключения OTA-обновлений и удаления предустановленного мусорного программного обеспечения.
* **Для чего:** Автоматически отключает неработающие OTA-обновления и облегчает удаление предустановленного мусорного ПО (bloatware) с Lenovo Xiaoxin Pad Pro GT (TB710FU) через ADB.
* **Особенности:** Включает отдельные скрипты как для китайской (CN), так и для глобальной (EN/RU) прошивок. Оптимизирует сервисы Google и применяет RU-локаль на китайской прошивке. Использует безопасное удаление через `pm uninstall --user 0` с возможностью полного восстановления приложений. Легко настраивается редактированием списка пакетов в `.bat`-файле.

### 📖 2. [Инструкция по прошивке TB710FU](TB710FU-flash-guide_ru.md) *(В разработке)*
Пошаговое руководство по полной прошивке, восстановлению и обслуживанию устройства через `Fastboot`, `MiFlash` или `QFIL`.
* **Для чего:** Установка глобальной прошивки, восстановление устройства после неудачных модификаций (unbrick), восстановление системных разделов.
* **Особенности:** Подробные инструкции для платформы Snapdragon, включая настройку драйверов, разблокировку загрузчика и методы спасения «кирпичей» (режим EDL).

### 🌍 3. [Смена региона TB710FU](TB710FU-region-code-changer_ru.md) *(В разработке)*
Минималистичный, портативный и безопасный инструмент для изменения кода региона.
* **Для чего:** Активация Widevine L1 (HD-видео), сертификация Google Play, смена региональных настроек, включение локальных ИИ-функций.
* **Особенности:** Работает через встроенный PowerShell или ADB. Не требует сложных зависимостей (Python и т.д.).
